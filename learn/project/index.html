マネジメント系

プロジェクトマネジメントの基礎｜作業のつながりと数字の意味を読む

依存関係、クリティカルパス、余裕時間、EVMを、作業順と分子・分母を明確にして学ぶ基本情報技術者試験のプロジェクトマネジメント入門です。

最終更新：2026年9月15日 ／ 編集：FE Study編集部

プロジェクトの計算問題は、公式を当てはめる前に作業の依存関係と、指標が何を比べているかを理解する必要があります。作業ネットワークを描き、開始できる条件、最も遅れる経路、計画・実績・出来高の三つを分けると、結果に理由を付けられます。

このページで学ぶこと
  1. 到達目標
  2. 1. 作業は、開始条件と完了条件で結ぶ
  3. 2. EVMは、計画・完了した価値・実際の費用を比べる
  4. 3. 数字は、次の判断に使う
  5. 用語・考え方の比較
  6. 手順付きの例
  7. 確認と演習

この分野で身に付けること

  • 作業の前後関係を図にし、同時に進められる作業を判断できる。
  • クリティカルパスと余裕時間を、完了日に対する影響で説明できる。
  • PV、EV、ACの意味を分けて、EVMの指標を読める。

1. 作業は、開始条件と完了条件で結ぶ

作業ネットワークでは、どの作業が終われば次を始められるかを矢印で表します。作業を順番に並べるだけでなく、並行して進められる部分と、合流を待つ部分を明らかにすることが目的です。各経路の所要日数を足し、プロジェクト全体の完了日を決める経路を探します。

クリティカルパス上の作業が遅れると、ほかに余裕がなければ全体の完了も遅れます。一方で、余裕時間がある作業は一定の範囲で遅れても直ちに全体へ影響しません。余裕は作業の重要度の評価ではなく、日程への緩衝を表す値です。

2. EVMは、計画・完了した価値・実際の費用を比べる

PVは計画上その時点までに使う予定だった予算、EVは実際に完了した作業を予算で評価した価値、ACは実際に使った費用です。EVは作業の進み具合をお金の単位で表す考え方で、支払った額そのものではありません。

SPIはEVとPVを比べ、計画より進んでいるかを読む指標です。CPIはEVとACを比べ、投入した費用に対してどれだけの価値を得たかを読みます。公式だけでなく、分子と分母にどの値が入るかを文章で言ってから計算します。

3. 数字は、次の判断に使う

進捗が遅れていると分かったとき、単に人を増やせばよいとは限りません。依存関係、必要な技能、作業の分割、品質への影響を確認します。試験では指定された指標の意味を問いますが、実務ではリスクや変更管理と合わせて判断します。

報告では、数字だけでなく基準時点と前提をそろえます。作業が何％終わったかの見積りと、受入済みの成果物に基づく進捗は違う場合があります。問題文がどの定義で進捗を測るかを読みます。

用語・考え方の比較

EVMで比べる三つの値
値意味混同しやすい点
PV計画時点で予定した予算実際に使った費用ではない
EV完了した作業を予算で評価した価値進捗率だけの数値ではない
AC実際に使った費用完了した価値と一致するとは限らない

例：SPIを読む

ある時点でEVが75万円、PVが100万円なら、SPIを求めます。

  1. SPI = EV ÷ PV とし、75 ÷ 100 = 0.75。
  2. 1より小さいため、計画で予定した価値に対し完了した価値が少ない。
  3. 遅れの原因と、クリティカルパスに影響する作業かを別途確認する。

ここで確認：SPIの数値だけで対策を決めず、どの作業が遅れているかへ戻って考えます。

確認してから、演習へ進む

間違えやすいポイント

  • 最も作業数が多い経路を、必ずクリティカルパスだと考えない。
  • EVを実費、ACを進捗の価値として入れ替えない。
  • 余裕時間がある作業を、全く管理しなくてよいと考えない。

自分で確かめる三つの手順

  1. 作業の前後関係を矢印で描き、経路ごとの日数を足す。
  2. PV・EV・ACに、それぞれ一文の日本語の意味を書く。
  3. 指標が1より大きい・小さいときの意味を、式を見ずに説明する。

この分野の演習問題

ガイドを読んだ後は、対応する3問で、理由を説明しながら理解を確かめましょう。 正答率は振り返りのための記録であり、本試験の評価点や合否を予測するものではありません。

  • 問20：作業Aは3日、Aの完了後に並行実行できる作業Bは4日、Cは6日かかる。BとCの両方が完了すると作業Dを2日で実施できる。最短所要日数はいくつか。
  • 問41：ある時点の計画価値PVは120万円、出来高EVは90万円、実コストACは100万円である。スケジュール効率指数SPI = EV / PV、コスト効率指数CPI = EV / ACとし、各指数が1未満なら計画より非効率と判断する。この時点の状況として適切なものはどれか。
  • 問42：作業Aは2日で完了する。Aの後にB（5日）とC（3日）を並行して行い、両方の完了後にD（4日）を行う。人員などの資源制約はなく、日数は連続した作業時間として扱う。全体の最短完了時点を遅らせずに、Cの開始だけを最も早い開始時点から何日遅らせられるか。
