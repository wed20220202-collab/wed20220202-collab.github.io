QUESTION 41

ある時点の計画価値PVは120万円、出来高EVは90万円、実コストACは100万円である。スケジュール効率指数SPI = EV / PV、コスト効率指数CPI = EV / ACとし、各指数が1未満なら計画より非効率と判断する。この時点の状況として適切なものはどれか。

出典：本サイト オリジナル教材（2026年）

本サイトで独自に作成。IPAの試験問題からの転載ではありません。

公開日：2026年8月31日

解答を一つ選んでください

選択肢を選んで、答え合わせをしましょう。

回答せずに正解・解説を確認する

正解：ア　SPIは0.75、CPIは0.90で、作業は計画より遅れ、出来高に対してコストが超過している

この表示だけでは、回答数や正答率は変わりません。

解説

SPIは90 / 120 = 0.75で、計画した出来高に達していません。CPIは90 / 100 = 0.90で、予算価値90万円分の作業に100万円を使っています。どちらも1未満なので、スケジュール面では遅れ、出来高に対するコスト面では超過です。

ア

指定された式の計算も、1未満の解釈も正しい説明です。

イ

PVとACを取り違えています。また、1未満は効率がよい状態ではありません。

ウ

分子と分母を逆に計算しています。

エ

指数自体は正しいですが、1未満の意味を逆に解釈しています。

関連知識

EVは実際に完了した作業を計画時の予算価値で表したものです。SPIだけから遅れが何日かまでは分かりません。CPIも最終的な総予算超過を確定するものではなく、現時点の効率指標です。

間違えやすいポイント

実コストACが計画価値PVより小さくても、完成した作業量EVがさらに小さければコスト効率は悪化しています。

覚え方

両方とも出来高EVが分子。予定と比べてSPI、実費と比べてCPI。

実務での意味

使った金額だけで進捗を判断せず、完了した作業の価値も合わせて報告します。
